# 🌿 Rime-四叶草输入法配置

一款为 macOS 鼠须管精心定制的智能输入法方案，融合五笔与拼音，兼顾效率与易用性。

## ✨ 核心特性

### 🎯 双方案无缝切换
- **🍀 四叶草拼音**：基于智能纠错的拼音输入方案，支持模糊音、emoji 表情、特殊符号
- **⌨️ 五笔86**：经典五笔字型86版，支持拼音反查（按 `z` 键）
- **五笔·拼音**：五笔与拼音混合输入，遇到不会输的字直接用拼音，无需切换方案

### 🧠 智能输入体验
- **智能纠错**：自动识别并修正常见输入错误（如 `tian` → `tain`、`hoa` → `hao`）
- **模糊音支持**：完美适配方言用户（n/l 不分、zh/z 不分、hu/f 不分等）
- **简拼输入**：支持首字母输入（如 `zhhr` → `zhuo hu ren`）
- **反模糊音**：为有需要的高级用户提供精确区分
- **自动补全**：智能补全拼音（`o` → `ou`、`on` → `ong`）

### 🎨 丰富的视觉主题
内置 13+ 精美主题，支持深色/浅色自动切换：

- **微信键盘系列**：微信键盘浅色/深色
- **Mac 系列**：Mac浅色/深色/绿/橙/浅蓝
- **经典主题**：玫枫、安静、幽能、日光石、夜光石、冷漠、谷歌、米兰、墨池、纯洁、星际争霸、北方浅色/深色

### 🔤 专业词库支持
- **THUOCL 专业词库**：动物、财经、汽车、成语、地名、食物、IT、法律、历史名人、医疗、诗词
- **搜狗新词**：收录最新网络热词
- **自定义短语**：支持用户自定义常用短语

### ⚙️ 精心定制的交互
- **圆圈数字选字**：①②③... 选号更直观
- **行内编辑**：编码直接显示在输入框中，候选框更简洁
- **毛玻璃效果**：模糊背景，现代感十足
- **自定义字体**：默认使用繁书楷（TsangerJinKai03-W04），视觉更优雅
- **智能标点**：中英文标点自动适配

## 📦 快速开始

### 安装
1. 确保已安装 [鼠须管](https://github.com/rime/squirrel)
2. 将本仓库所有文件复制到 `~/Library/Rime/`
3. 重新部署（点击菜单栏的鼠须管图标 → 部署）

### 基础操作

| 功能 | 快捷键/操作 |
|------|------------|
| 切换中英文 | `Ctrl` + `Space` 或 `Caps Lock` |
| 切换全半角 | 方案切换菜单 |
| 切换繁简 | `F4` 或方案切换菜单 |
| 开关 Emoji | 方案切换菜单 |
| 五笔反查拼音 | 按 `z` 然后输入拼音 |
| 翻页候选词 | `Comma/Period` 或 `[`/`]` 或 `-`/`=` |

### 主题切换
编辑 `squirrel.custom.yaml` 中的 `color_scheme` 和 `color_scheme_dark` 字段：

```yaml
patch:
  style:
    color_scheme: wechat_light        # 浅色主题
    color_scheme_dark: wechat_dark    # 深色主题
```

## 🎛️ 可配置开关

每个输入方案都包含以下可切换功能：

- **中英文模式**：中文/西文
- **全半角模式**：半角/全角
- **中英标点**：。，/．，
- **繁简转换**：简/繁
- **Emoji 表情**：🈚️/🈶️
- **特殊符号**：无符/符

## 📝 方案说明

### 🍀 四叶草拼音（默认方案）
最适合日常使用的拼音方案，特点：
- 结合搜狗输入法的输入习惯
- 默认开启 Emoji 表情支持
- 内置特殊符号快速输入
- 繁简切换一键完成
- 强大的智能纠错系统

### ⌨️ 五笔86
适合专业打字员的五笔方案，特点：
- 经典五笔字型86版
- 按 `z` 键可用拼音反查
- 支持词组输入和造词
- 高效专业的输入体验

### 🎯 五笔·拼音
五笔与拼音混合方案，特点：
- 五笔输入时可直接混入拼音
- 无需在五笔和拼音间切换
- 适合五笔熟练但偶尔需要拼音的场景

## 🔧 高级配置

### 添加自定义短语
编辑 `custom_phrase.txt` 文件，格式如下：
```
abc # 自定义内容
```

### 启用/禁用模糊音
编辑 `clover.schema.yaml` 中的 `speller/algebra` 部分，注释/取消注释相应的模糊音规则。

### 同步配置
取消注释 `default.custom.yaml` 中的 `sync_dir` 并设置你的同步路径：
```yaml
# sync_dir: '/path/to/your/sync/folder'
```

## 🌟 设计理念

本配置遵循"**效率优先，体验至上**"的设计理念：

1. **无缝切换**：五笔与拼音无需来回切换，提升输入效率
2. **智能容错**：智能纠错和模糊音减少输入错误，降低学习成本
3. **视觉愉悦**：精美的主题和动画效果，让输入成为享受
4. **专业可靠**：基于 RIME 强大引擎，稳定高效，可深度定制
